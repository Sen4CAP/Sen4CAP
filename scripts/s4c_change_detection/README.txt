Orchestrator Handler

1. Identify the ref site. We can either have a config key or if the key is not set, we can try determine it by name (Ex. if our site ends with 2023, we can search a site with the same prefix but ending with 2022)
2. Check the LPIS for each of the sites. If the LPIS are not present, then quit.
3. Launch MDB1, L4A and then Bare Soil for each of the sites.
4. Map the parcels ids
5. Process each site MDB1 and MDB4
6. Do comparisons & etc.
